Playback steps: the notes sent
Playback steps send a MIDI note to MultiTracks Playback over network MIDI. In Playback, map these notes (Settings › MIDI › MIDI Control) on the same channel.
Steps run in order. Nothing runs by itself: press Run (here, on Home or on the Plan). If an Admin turns on automatic macros, they ask before they run and show which devices are ready. If something isn’t connected, the app checks again every 5 minutes. Every run is written to the service log.
